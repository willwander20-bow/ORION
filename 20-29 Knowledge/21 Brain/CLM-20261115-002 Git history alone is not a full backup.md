## Claim

Git history is possibly not a complete backup of a note collection. Keep Git history and a separate backup.

## Context and conditions

One short statement from one opinion source. The article cites Obsidian's guidance that sync is not backup. The Brief did not check the reasons against the cited page. The Brief gives no information on which cases of loss or damage Git fails to cover. General advice.
